# Top Lane Coaching - Analysis Framework

## 1. Wave Management
- **Freeze** : freeze devant ta tour pour zoner l'ennemi du CS. Si tu as un avantage, slow push 3 vagues et crash sous la tour pour plonger ou roam.
- **Slow push** : laisser 1-2 caster minions en plus, la wave grossit naturellement. Crash 3 vagues puis dive/roam/reset.
- **Fast push** : push rapide pour reset ou forcer un back ennemi. Utilisé quand tu as besoin de back rapidement.

## 2. Teleport Usage
- **TP** : ne TP jamais pour save ta lane sauf si tu perds 2+ vagues + des plaques. Garde TP pour les fights objectifs (drake, herald).
- **TP flanc** : en mid/late game, TP sur un ward de flanc pour les teamfights objectives.

## 3. Split Push
- **Split push apres 14 min** : push une side lane quand ton equipe est visible ailleurs sur la map.
- **Pression** : si 2+ ennemis viennent sur toi, ton equipe doit prendre un objectif.
- **Vision** : toujours avoir des wards profondes quand tu split push pour voir les rotations ennemies.

## 4. Island Mentality
- **1v1 focus** : le top est souvent un 1v1 isole. Les matchups et les power spikes sont critiques.
- **Jungle tracking** : ward le tri-bush ou river bush cote du jungler ennemi. Deep ward entree jungle ennemie si possible.
- **Respect les timers** : quand tu ne sais pas ou est le jungler ennemi, joue safe cote ta tour.

## 5. Common Coaching Review Points
- **Mort en overextend** : la cause #1 de morts en top est l'overextend sans vision.
- **TP gaspille** : TP utilise pour revenir en lane au lieu de pour un objectif = TP perdu.
- **CS diff** : en top, le CS diff est directement correle aux trades et wave management.
- **Plaques** : 160g par plaque, prendre des plaques apres un kill ou un back force est essentiel.
